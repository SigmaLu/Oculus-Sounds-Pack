# Meta Quest Link UI Sounds/smt

A collection of UI sounds and other audio taken from the assets in the `mtql` folder of the Meta Quest Link app.

## What's inside

- Menu and interface sounds (clicks, hovers, confirmations, etc.)
- Other miscellaneous sound effects found in the same assets folder

## Source

All audio comes from the `C:\Program Files\Oculus\Support\oculus-dash\dash\assets\raw\audio_dash` assets folder of Meta Quest Link.

## Usage

1. Download
2. Browse the sound files and use them for personal projects, testing, or reference.
